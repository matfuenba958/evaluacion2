# Evaluacion 2 - Biblioteca Nacional
Script en Python para calcular rutas utilizando la API de Graphhopper.

## Instrucciones de uso
1. Asegúrese de tener instalada la librería requests (`pip install requests`).
2. Ejecute el script con `python3 script_rutas.py`.
3. Ingrese la ciudad de origen y destino cuando la consola lo solicite.
4. Para cerrar la aplicación, ingrese la letra 's' o la palabra 'salir'.
